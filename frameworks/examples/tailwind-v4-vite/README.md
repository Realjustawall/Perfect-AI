# Tailwind CSS v4 × Anime.js v4 × Three.js demo

This project requires npm dependencies (not copied into ZIP). It is source code, not a prebuilt tested binary.

```bash
npm install
npm run dev
npm run build
```

Stack: Tailwind v4 `@tailwindcss/vite`; CSS-first theme; named `@container` responsive layout; dark preference; native form; Anime.js onScroll; real IcosahedronGeometry wireframe; bounded DPR and a no-WebGL fallback. Browser test under RTL, reduced motion, zoom and WebGL disable. Network package install was unavailable at authoring time, so the production build was not executed here.
