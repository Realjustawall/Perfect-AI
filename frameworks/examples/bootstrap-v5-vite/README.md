# Bootstrap v5.3 RTL × Anime.js v4 × Three.js

```bash
npm install
npm run dev
npm run build
```

Official RTL CSS is imported from the installed Bootstrap package and bundle JS is imported once for Collapse. Demo uses `data-bs-theme`, semantic forms, `row-cols-*` responsive Grid, scroll animation, real TorusKnot Three.js geometry, resize observation and 2D fallback. Library install/build requires npm registry, unavailable at authoring time. The JavaScript was syntax checked; visual runtime is not claimed tested.
