# Source provenance and rights

- New `ztp-*` skills and `patterns/implementation-atlas/*`: original implementation recipes authored for the Perfect_AI pack; not byte-for-byte copies of animejs.com, GitHub or VibeFarsi.
- New `ztg-*` skills and `github-curation/*`: original integration briefs and URL pointers, **not vendored upstream SKILL.md**. License notes are reminders to verify the original repository and selected release; no automatic installation or source retrieval is performed.
- Previous `skills/*`, templates, registry, examples, and tools: copied intact from the previously generated OMEGA chat artifact except the README and appended master guidance. Prior archives remain in `legacy-archives/` for exact historical reference.
- The 279 VibeFarsi item specifications are local authored descriptions and inventory; their original source components are not included. Official CLI installation is optional and requires reviewing dependencies/source. No MCP.
- Third-party code from GitHub was not downloaded or bundled because this build environment could not retrieve raw source; user's network-connected machine can inspect repos after extraction.
- Anime.js v4, Three.js, Motion, GSAP and browser APIs are separate technologies. The patterns show integration recipes; dependency usage is subject to installed version and its license.
- Static parsing and file-structure tests do not establish production suitability, accessibility compliance, GPU performance or pixel-exact identity with the reference website. Run actual browser testing after using these recipes in a real app.
