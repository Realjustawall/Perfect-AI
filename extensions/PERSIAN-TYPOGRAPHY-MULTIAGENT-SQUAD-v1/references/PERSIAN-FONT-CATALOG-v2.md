## Practical selection order

1. **Vazirmatn** — default for Persian product UI, forms, dashboards and general interface text. Check the exact release and preferred Farsi digit variant.
2. **Estedad** — contemporary UI alternative; verify the exact subset and glyph test.
3. **Noto Naskh Arabic** or **Parastoo** — editorial/reading alternatives when their Persian glyph coverage and style fit are confirmed.
4. **Noto Sans Arabic / Noto Sans Arabic UI / Noto Naskh Arabic UI / Noto Kufi Arabic** — useful families, but Arabic script support by itself is not proof that a particular file contains all Persian-specific glyphs.
5. **Lalezar** — display/headline use, not a default body font.
6. **Sahel, Shabnam, Samim, Gandom, Tanha, Nahid and Vazir Code** — choose according to source status and purpose; verify exact assets, license and coverage before release.
7. **IBM Plex Sans Arabic, Readex Pro, Noto Nastaliq Urdu and Amiri** — candidate families with additional license/coverage/design checks. Nastaliq is a distinct calligraphic style, not a drop-in UI default.

## Use-rights statement for agents
The project instructions authorize use of catalogued fonts **only within the applicable license of the exact release**. For an exact package verified as SIL OFL 1.1, commercial application use and bundling are allowed subject to OFL conditions. When redistributing font binaries, preserve the required license/copyright information and Reserved Font Name obligations; do not sell the font by itself. Entries labeled `verify-before-use` are not pre-cleared and must not be treated as blanket legal permission.

## Required pre-release glyph and rendering check
Test `پ چ ژ گ ک ی آ ؤ ئ ۰۱۲۳۴۵۶۷۸۹` and `این یک نمونهٔ آزمایشی برای بررسی تایپوگرافی فارسی و اعداد فارسی است.` with the actual loaded font. Verify the actual asset loads, Persian-specific characters render with the intended face, joining/shaping works, digits are intentional, RTL and embedded LTR are coherent, and desktop/mobile layouts do not clip. A CSS family declaration alone does not pass the gate.
