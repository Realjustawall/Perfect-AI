# افزونهٔ تیم چندایجنتی و تایپوگرافی فارسی

این افزونه **فقط افزوده** شده است و فایل‌های نسخهٔ قبلی را حذف یا جایگزین نمی‌کند.

## چه چیزی اضافه شده؟
- ۱۳ تعریف نقش ایجنت (Orchestrator، پژوهشگر، معمار، طراح، پیاده‌ساز، متخصص Motion/Isometric، متخصص فارسی و RTL، دسترس‌پذیری، کارایی، تست، مجوزها/امنیت، بازبین کد و ممیز انتشار).
- Skillهای متناظر برای هماهنگی و تخصص هر نقش.
- فهرست فونت‌های فارسی/عربی با لینک منبع، وضعیت پوشش حروف فارسی، نوع استفاده و وضعیت مجوز.
- یک الزام غیرقابل‌چشم‌پوشی: اگر محتوای محصول فارسی است، باید فونت واقعاً پشتیبان فارسی بارگذاری و آزمایش شود؛ فونت پیش‌فرض Vazirmatn است.
- دستورالعمل مجوز OFL: استفاده در محصول تجاری مجاز است، اما شرایط مجوز هنگام بازتوزیع فایل فونت باید رعایت شود و فایل فونت به‌تنهایی فروخته نشود.

## راه‌اندازی تیم ایجنتی
1. ابتدا `skills/ztx15-multiagent-orchestrator/SKILL.md` را بارگذاری کن.
2. نقش‌های `agents/*.md` را به‌عنوان دستورالعمل ایجنت‌های تخصصی در پلتفرم میزبان تعریف کن.
3. پژوهش و برنامه‌ریزی را موازی انجام بده، اما فایل‌نویسی را با محدوده‌های جداگانه انجام بده تا ایجنت‌ها هم‌زمان یک فایل را تغییر ندهند.
4. ایجنت تایپوگرافی فارسی باید قبل از تحویل، لودشدن فونت و آزمایش `پ چ ژ گ ک ی` و اعداد فارسی را تأیید کند.
5. ایجنت ممیزی انتشار باید گزارش بدهد که کدام تست واقعاً اجرا شده و کدام مورد فقط پیشنهادی است.

این بسته **تعریف نقش و گردش‌کار** فراهم می‌کند؛ ایجنت‌های اجرایی را در حساب یا ابزار میزبان به‌صورت خودکار ایجاد یا متصل نمی‌کند. اجرای موازی واقعی به پلتفرمی بستگی دارد که این فایل‌ها در آن بارگذاری می‌شوند.
