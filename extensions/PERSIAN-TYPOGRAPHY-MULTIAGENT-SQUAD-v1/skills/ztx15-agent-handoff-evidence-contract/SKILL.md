# Agent handoff evidence contract

Every specialist must return a structured handoff: `summary`, `paths_read`, `paths_changed`, `sources`, `tests_run`, `test_results`, `assumptions`, `risks`, `next_owner`. Keep it concise but actionable.

Use official documentation for fast-changing APIs. Report dates/versions when relevant. Distinguish source-confirmed claims from hypotheses. If no browser/build/test execution was possible, say so and provide an executable next step rather than a false pass.
