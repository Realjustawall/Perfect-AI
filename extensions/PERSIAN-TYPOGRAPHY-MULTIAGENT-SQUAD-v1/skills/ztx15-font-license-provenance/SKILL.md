# Font license and provenance audit

For each font used or bundled, record its upstream repository, exact release/tag/commit, license filename/version, copyright text, Reserved Font Name declarations, asset URL, local path, and whether binary redistribution occurs.

OFL 1.1 generally allows commercial use and bundling under its terms, but font files are not to be sold alone; bundled/redistributed copies must carry the applicable copyright and license information. Preserve reserved-name conditions and do not put the font itself under another incompatible license. The application using the font does not become OFL merely because it uses the font.

Never extrapolate the license of one family to another, or from a README summary when the package includes a license file. Mark unknowns as `blocked/verify-before-use`; do not claim permission until confirmed. See official OFL FAQ: https://openfontlicense.org/ofl-faq/.
