# Technical references and provenance

All bundled new source code (`src`, tests, showcase, SVG frames and original SKILL.md texts) was independently authored for Perfect_AI. No vendored third-party source files, NPM tarballs, fonts, photography, nor copied GitHub demos. The links below are **references**, not dependencies in the ZIP. Respect each upstream license when separately installing it into a user project.
