# راهنمای فارسی Perfect_AI GITHUB DESIGN ENGINEERING

این افزونه ۹ قابلیت انتخاب‌شده را به بستهٔ قبلی می‌افزاید و فایل‌های گذشته را دست نمی‌زند.

- **Impeccable**: ممیزی، نقد هنری و اصلاح مرحله‌ای سایت.
- **Emil Design Engineering**: تصمیم‌گیری تخصصی دربارهٔ موشن و جزئیات تعامل.
- **Taste**: ساخت ترکیب‌بندی‌های واقعاً متفاوت با حفظ هویت برند.
- **shadcn/ui**: مدیریت Registry، کامپوننت‌ها و تست رابط‌های React.
- **Agent Browser**: کنترل مرورگر با CLI و بدون MCP.
- **React Doctor**: ارزیابی کد React با CLI رسمی پس از نصب آن.
- **Remotion**: طراحی ویدئو و تایپوگرافی فریم‌محور در React.
- **shadcn Improve**: برنامه‌ریزی بهبودهای مهندسی فقط‌خواندنی.
- **Prototype**: چند نمونهٔ واقعاً متفاوت و انتخاب کاربر از طریق پیش‌نمایش.

**تفاوت با دانلود کامل سورس GitHub:** داخل این افزونه Skillهای تازه‌نویسی‌شده و ابزارهای مستقل هستند؛ مخزن‌ها عیناً کپی نشده‌اند. انتقال فایل‌های اصلی فقط با بررسی و رعایت مجوز و ابزار اختیاری `sync_upstreams.py` امکان‌پذیر است.

برای Codex، بعد از نصب، `$ztgc-github-design-engineering-master` را فعال کن. این افزونه نسخهٔ Jiro نیست و به آن کاری ندارد.
