# DTCG tokens and brand source

This is a **demonstration palette, not the user's confirmed brand palette**. Replace tokens with approved brand JSON before production; preserve semantic references and test generated CSS. Run `npm install` and `npm run build`; output should be `build/tokens.css`. Tailwind v4 and Bootstrap v5.3 integration examples are in this folder; include them only for the framework your project actually uses. `@theme` mapping is a Tailwind v4 construct; use compatible version.

Verify WCAG AA contrast after generating and rendering CSS. Do not claim complete accessibility from color ratio alone. RTL should use logical CSS properties and per-script font families from licensed/self-hosted sources.
