## Scope and limitations

The Isometric public docs are the basis for the stack and registry details. The specialist documents are newly-authored implementation playbooks intended to be loaded selectively. No claim is made that every current component prop has been exhaustively re-tested locally. Per-component props, registry metadata, source and license should be checked against the current upstream pages when implementing a real project.
