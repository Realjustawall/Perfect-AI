# بستهٔ افزایشی مهارت‌های Isometric، تعامل و ایجنت

این افزونه **۳۲۱ مهارت جدید** اضافه می‌کند: یک Skill راهبر ویژهٔ `isometric.buildlab.in` و ۳۲۰ مهارت تخصصی در فایل‌های مستقل `SKILL.md`. هیچ Skill فعلی جایگزین یا حذف نمی‌شود.

## چرا برای این سایت مناسب است؟

طبق مستندات عمومی سایت، Isometric یک رجیستری shadcn برای شکل‌ها و کنترل‌های ایزومتریک React است؛ راه‌اندازی اعلام‌شده به React 19، Tailwind CSS v4، فایل `components.json` و CLI شادکن متکی است. کد کامپوننت‌ها به‌صورت سورس قابل‌ویرایش نصب می‌شود، موتور در `lib/isometric/` و متغیرهای سبک اختصاصی با پیشوند `--iso-*` هستند. برای هر کار مرتبط با این سایت ابتدا `ztx14-isometric-buildlab-master` را بخوانید.

## دسته‌ها

- رجیستری و نصب امن کامپوننت‌ها
- انیمیشن موس و Pointer، hover و spring
- picking و hit-testing هندسهٔ ایزومتریک
- ریسپانسیو، موبایل، تغییر جهت و اندازهٔ کانتینر
- SVG، هندسه و رسم خطوط
- React، shadcn، Radix و Tailwind v4
- دسترس‌پذیری، کیبورد، لمس و reduced motion
- کارایی، حلقهٔ انیمیشن و توقف خارج از viewport
- ارکستریشن ایجنت‌ها، تقسیم وظایف و گزارش مبتنی بر شواهد
- تست مرورگر، تصویر، تعامل و عملکرد
- تم، توکن‌ها و هماهنگی هویت بصری
- World، بلوک‌ها، inventory و تعاملات چندبخشی
- تاب‌آوری رجیستری، امنیت و منشأ کد
- انیمیشن اسکرول و حرکت سینمایی

## روش استفاده

۱. نصب را با نصب‌کنندهٔ معمول Perfect AI و حالت پیش‌نمایش انجام دهید؛ این افزونه در پوشهٔ `extensions/.../skills/` است و به‌صورت Skill جداگانه قابل نصب خواهد بود.
۲. برای هر درخواست فقط مهارت راهبر و چند مهارت واقعاً مرتبط را بارگذاری کنید؛ همهٔ ۳۲۱ مورد را هم‌زمان وارد context نکنید.
۳. پیش از تغییر، نسخه‌های واقعی پروژه، `components.json`، فایل‌های نصب‌شده و تست‌های موجود را بررسی کنید.
۴. فایل‌های قبلی را بازنویسی نکنید و تست اجرا‌نشده را موفق گزارش ندهید.
