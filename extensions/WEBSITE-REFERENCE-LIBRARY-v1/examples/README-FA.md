# نمونه‌های کتابخانهٔ مرجع طراحی وب

- `brands/` شامل ۴۹۴ مرجع مستقل است؛ در هر پوشه، فایل‌های منبع همان مرجع حفظ شده‌اند.
- `gallery-site/` یک گالری محلی و responsive برای جست‌وجو و مرور این مرجع‌هاست.
- این موارد به‌عنوان **نمونه/مرجع طراحی** ارائه می‌شوند، نه صفحات زنده یا ادعای مالکیت/تولید وب‌سایت‌های نام‌برده‌شده.
- برای راهنمای اجرا و سیاست عدم ترکیب خودکار، فایل `../README-FA.md` را ببینید.
