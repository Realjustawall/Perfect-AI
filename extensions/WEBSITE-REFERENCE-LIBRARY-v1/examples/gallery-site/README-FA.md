# گالری مرور نمونه‌های طراحی وب

این نمونه برای مرور کتابخانهٔ مرجع افزونه است و خودش هیچ تمی را روی سایت مقصد اعمال نمی‌کند.

از ریشهٔ مخزن اجرا کنید:

```bash
python -m http.server 8000
```

سپس این مسیر را باز کنید:
`http://127.0.0.1:8000/extensions/WEBSITE-REFERENCE-LIBRARY-v1/examples/gallery-site/`

کارت‌ها از `catalog.json` ساخته می‌شوند و به چهار فایل اصلی هر مرجع لینک می‌دهند. صفحه بدون framework و وابستگی بیرونی نوشته شده و برای viewportهای کوچک تا عریض responsive است.
