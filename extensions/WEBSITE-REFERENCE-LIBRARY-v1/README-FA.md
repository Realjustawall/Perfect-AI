# کتابخانهٔ مستقل نمونه‌های طراحی وب — Perfect AI

این افزونه ۴۹۴ مرجع طراحی وب را از فایل ورودی `TEMPS.rar` در مسیر مستقل `examples/brands/` نگه می‌دارد. هر مرجع، فایل‌های اصلی `DESIGN.md`، `theme.css`، `tokens.json` و `variables.css` خود را دارد؛ محتوای این فایل‌های مرجع بازنویسی نشده است.

## هدف و نحوهٔ استفاده

این مجموعه **مرجع طراحی قابل جست‌وجو** است، نه ۴۹۴ وب‌سایت آمادهٔ اجرا یا ادعای نمونه‌کار ساخته‌شده توسط Perfect AI. برای مرور بصری فهرست، گالری محلی را از ریشهٔ مخزن با دستور زیر اجرا کنید:

```bash
python -m http.server 8000
```

سپس `http://127.0.0.1:8000/extensions/WEBSITE-REFERENCE-LIBRARY-v1/examples/gallery-site/` را باز کنید. سرور محلی لازم است چون صفحهٔ گالری فایل `catalog.json` را با `fetch` می‌خواند.

برای جست‌وجوی دقیق‌تر در توضیحات، توکن‌ها و CSS مرجع‌ها:

```bash
python extensions/WEBSITE-REFERENCE-LIBRARY-v1/tools/find-website-reference.py "editorial serif" --deep
python extensions/WEBSITE-REFERENCE-LIBRARY-v1/tools/find-website-reference.py "dashboard" --theme dark --deep
```

هر رکورد چهار لینک مستقیم به فایل‌های همان مرجع دارد. فهرست قابل‌ماشین‌خوانی در `catalog.json` است.

## قواعد جداسازی

- کل مجموعه را به‌صورت یک‌جا در prompt یا پروژه وارد نکنید؛ ابتدا جست‌وجو و فقط ۱ تا ۳ مرجع مرتبط را باز کنید.
- انتخاب برند/هویت فعلی پروژه بر مرجع‌ها اولویت دارد. مرجع، منبع الهام است و به‌طور خودکار تم یا پالت پروژه را عوض نمی‌کند.
- فایل‌های `theme.css` چند مرجع را با هم وارد نکنید. در صورت نیاز به اقتباس، توکن‌های منتخب را به design tokenهای پروژه نگاشت کنید و نام متغیرهای CSS را namespace کنید.
- مقیاس فونت، فاصله، radius، عرض container و breakpointها را بین مرجع‌ها مخلوط نکنید. یک مقیاس سازگار بسازید و آن را در عرض‌های موبایل تا دسکتاپ بررسی کنید.
- این آرشیو شامل تصویر یا asset اجرایی نیست؛ اگر مرجعی به فونت، تصویر یا کتابخانهٔ بیرونی اشاره می‌کند، مجوز و دسترسی آن باید جداگانه بررسی شود.

## منشأ و حقوق

فایل ورودی `TEMPS.rar` توسط کاربر ارائه شده است. نام‌ها و محتوای منبع برای ردیابی حفظ شده‌اند؛ مجوز حقوقی تک‌تک برندها/مرجع‌ها در این بسته مستقلاً تأیید نشده است. این گالری نباید به‌عنوان اثبات مالکیت یا نمونه‌کار اصلی Perfect AI معرفی شود.
