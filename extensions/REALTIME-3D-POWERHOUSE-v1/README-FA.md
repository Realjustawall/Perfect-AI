# Perfect_AI — REALTIME 3D POWERHOUSE

این افزونه شامل پنج سامانهٔ مستقل است که به مجموعهٔ موجود اضافه می‌شوند، بدون هیچ بازنویسی: نمایش Gaussian Splatting با فایل محلی `.splat`، ویرایشگر گراف Shader و تولید کد TSL، افکت‌های سینمایی با postprocessing، ترکیب فریم‌های ویدئو با بافت سه‌بعدی به کمک Mediabunny، و ویرایشگر صحنهٔ Three.js/Threepipe.

**نصب دمو:** وارد `examples/web-studio` شوید؛ `npm install` و سپس `npm run dev` را اجرا کنید. برای اجرای نمونه به پکیج‌های npm نیاز است؛ CDN و MCP لازم نیست.

**نصب Skillهای Codex:** اسکریپت `install/install-windows.ps1` به صورت پیش‌فرض تنها پیش‌نمایش دارد؛ با `-Execute` فایل‌های جدید را اضافه می‌کند. اگر Skill قبلی هم‌نام وجود داشته باشد از آن عبور می‌کند.

**دقت فنی:** تست‌های Node می‌توانند ماژول‌های مستقل را بررسی کنند اما کیفیت GPU یا عملکرد گوشی را اثبات نمی‌کنند. کد TSL بسته به نسخهٔ Three.js باید واقعاً کامپایل شود. پروژهٔ TSL Node Editor آزمایشی است. پشتیبانی از `.ksplat`، ویرایش کامل فایل GLB در Native Editor و خروجی ویدئو با صدای دقیق به صورت ادعای کامل نشده‌اند؛ مسیر تکمیل و تست آن‌ها در Skillها مستند شده است. مجوز و حقوق مدل‌های سه‌بعدی باید رعایت شود.
