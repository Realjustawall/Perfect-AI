## تصمیم دربارهٔ ابزارها

| ابزار/تکنولوژی | اولویت پیشنهادی | دلیل |
|---|---|---|
| Isometric engine + SVG | پیش‌فرض برای اشیای خود سایت | موتور خود سایت projection، picking، spring و حلقهٔ مشترک را فراهم می‌کند. |
| Motion for React | بالا برای UI/DOM | مناسب hover/gesture، `useMotionValue` و `useSpring`; فقط برای خواص خارج از مالکیت موتور Isometric. |
| Playwright | بالا برای رگرسیون | تست مرورگر واقعی، pointer journey و screenshot baseline. |
| Vitest Browser / Storybook | بالا برای چرخهٔ کامپوننت | تست رفتار و accessibility به‌صورت متمرکز. |
| GSAP + ScrollTrigger | متوسط/شرطی | برای timeline پیچیده، scrub و pinning؛ نه یک fade ساده. |
| CSS scroll timelines | متوسط/شرطی | برای mapping سادهٔ scroll، همراه با feature detection/fallback. |
| Lenis | پایین/اختیاری | فقط وقتی smooth-scroll هماهنگ‌شده لازم است؛ native scroll را بی‌دلیل جایگزین نکن. |
| Rive/Lottie | اختیاری | برای انیمیشن vector تألیف‌شده؛ Rive در صورت state machine و Lottie برای playback. |
| React Three Fiber / Three.js | فقط برای نیاز واقعی 3D | سایت پایهٔ SVG/line art است؛ WebGL هزینهٔ اجرا، دسترس‌پذیری و fallback می‌آورد. |

## نمونهٔ انتخاب سریع

- **«کارت زیر موس کمی tilt شود»** → `animation-ownership-boundary` + `motion-react-pointer-spring` + `reduced-motion-system`.
- **«خود figure یا skyline به موس واکنش نشان دهد»** → `isometric-component-selection` + `svg-pointer-hit-testing` + مهارت تخصصی موجود در افزونهٔ v1؛ ابتدا از موتور خود Isometric استفاده کن.
- **«صفحه با scroll یک روایت انیمیشنی چندمرحله‌ای داشته باشد»** → `gsap-responsive-scroll` یا برای حرکت ساده `css-scroll-timelines`، به‌همراه reduced motion و Playwright.
- **«آبجکت با موس drag شود»** → `pointer-capture-drag` + `world-pan-zoom-coordinate-stability` + تست e2e.
- **«حرکت در موبایل روان بماند»** → `responsive-motion-capabilities` + `reduced-motion-system` + تست واقعی Touch.
