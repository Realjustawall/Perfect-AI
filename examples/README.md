# Executable labs

- `live-lab`: Anime.js v4 + Three.js true 3D, scroll-bound phases. Requires `npm install`.
- `responsive-lab`: HTML/CSS/JS offline demo with adaptive layout, container queries, RTL, searchable list, functional menu/theme/form, reduced motion. No install; Chromium matrix tool can evaluate it.
- `motion-engines-lab`: Anime.js, Motion animate(), GSAP and Animate.css (each isolated target). Requires `npm install` and `npm run dev`; don't bundle all four in production needlessly.
