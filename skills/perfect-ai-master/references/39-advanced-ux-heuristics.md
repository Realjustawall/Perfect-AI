# Advanced UX/UI research, interaction and product architecture

Define user tasks and success metrics *before* visuals. Journey mapping: entry → intent → action → system status → outcome → recovery. Architecture: information scent, findability, nav depth, empty/loading/error/offline/success and undo. Progressive disclosure to prevent clutter. Make feedback specific, timely, recoverable; never fake interactions.

Per view checklist: headline promises actual value; dominant action is obvious; forms request only necessary data; users can reverse destructive changes; focus order mirrors DOM, not CSS reordering; text contrast compliant; content is scan-friendly, accessibility explicit; responsive behavior chosen by task hierarchy; animations clarify causality not disguise latency.

Microcopy guidelines Persian: natural concise labels, clear field errors, polite precise feedback without shifting blame, avoid translation artifacts. English technical identifiers isolate bidi. Use skeleton only for loading, not to hide empty data. Distinguish critical vs decorative 3D; fallback must preserve access to information.
