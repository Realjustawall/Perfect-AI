# DevOps, CI/CD, PWA and reliability

Document prerequisites, package manager lockfile, pinned dependencies, .env template (no secrets), build/typecheck/lint/tests, CSP/headers where appropriate, caching and asset content hashes, service worker update/rollback if a PWA exists. CI test responsive smoke and accessibility, guard large asset budgets; surface failing screenshots rather than auto-blessing. Read third-party code licenses before local bundling. Offline shell is optional; do not cache user-sensitive content without a reason. Build with artifacts and clear versioned release notes.
