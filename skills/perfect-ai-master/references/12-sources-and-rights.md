## Accuracy boundaries

Anime.js home highlights core engine tool families, but 'every animation on the website' is not a fixed/version-independent list: examples, marketing visuals and docs are updated. This skill provides comprehensive API-family treatment and an original motion pattern atlas. It **does not** include uninspected proprietary HTML/assets or guarantee equivalence to the exact site's live animated geometry.

Three.js is a general rendering library, not a closed collection of 'all possible' animations. Covers official animation classes and practical design patterns; refer to docs/examples for up-to-date APIs.

VibeFarsi registry entries were manually transcribed from public catalog listings and indexed by slug; **catalog + implementation guidance** is provided, not a verbatim copy of the site's 14 maintained SKILL.md sources. For current canonical sources, run the VibeFarsi CLI / read skill pages, check terms/license and version. The scripts deliberately avoid silently fetching or executing unknown remote code and only run on direct invocation.

Respect original authors' copyright, licenses, attribution, and asset rights. Do not strip logos/credits from downloaded templates if a license requires keeping them. Check every installed source package's license before redistribution. All local guidance is newly written for this package and can be adapted by the user.

## VibeFarsi source installation without external agent connectors

Use the published CLI from https://vibefarsi.ir/docs in a compatible React + Tailwind v4 project. This pack does not require or configure any MCP connection.

Their listed 14 items break down into 7 runnable VibeFarsi agent Skills, 6 Markdown guides without SKILL.md frontmatter, and 1 separate external MIT licensed project (`persian-writing` maintained at `ali2000hos/persian-writing`). The 14 local `zt-*` files in this package are all independently authored Codex Skills, not VibeFarsi originals.
