# Codex Skill composition — how to deploy the entire pack intelligently

Skill names are an index, not an instruction to load all files into context. Route by task tags and read appropriate reference(s) before editing. For large work choose **master + 2–6 focused skills**, then draw implementation recipes as needed. Prioritize requirements and verified APIs; avoid using multiple incompatible animation runtimes on the same nodes. Record provenance and license before importing upstream GitHub. All 279 VibeFarsi item guides are retained; official source is not magically included. Do not use MCP.

Audit protocol: inspect repo → derive responsive scene/component requirements → assign design/motion/GPU ownership → establish light/dark + semantic tokens → build working HTML fallback → add interactions → add GPU/complex effects → test matrix → write truthful test report. Avoid promises of 100% fidelity to an uninspected proprietary website.
