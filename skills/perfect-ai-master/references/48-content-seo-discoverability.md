# SEO, structured content and discoverability

Single H1 per view in semantic hierarchy; metadata per route; correct canonical/OG description and RTL language alternates; stable share images; robots and sitemap reflect actual pages; structured data only for real content and schema-valid types. Page needs meaningful text before JS and without GPU. Avoid invented customer counts, reviews and fake awards. Use accessible rich descriptions not SEO keyword stuffing. Performance and responsive design influence experience; measure field data rather than promising ranks.
